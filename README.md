# GetWell 4.0

Android clinic-management starter project. Current build is an installation smoke test only; **not suitable for patient records or clinical use**. A4 scanning, PDF attachments, patient profiles, authentication, encryption, audit logs, and backup/restore remain to be implemented and validated.

GitHub Actions → Build Android APK → Artifacts → GetWell4-debug-apk downloads a ZIP containing the debug APK. Keep real patient data out of this public repository.
